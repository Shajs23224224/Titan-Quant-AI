# TITAN QUANT AI — Android v1.0.1

Publicación autorizada para compilar el cliente Android original. El archivo android-source.tar.gz contiene íntegramente el módulo Kotlin/Compose, Gradle, recursos, manifiestos y el empaquetador. SHA-256: ce637466aa3ebb665a3175cbdd82be34456037d594a53c740ecb8c5178b3c4b8.

Extraer con `tar -xzf android-source.tar.gz`. GitHub Actions verifica la integridad, compila, ejecuta lint y verifica la firma debug antes de publicar el ZIP. El APK requiere un servidor TITAN v1.0.0 externo y no incluye el motor neuronal local. El backend y los checkpoints permanecen en la distribución completa de investigación.
